# 景见

把景点照片与资料，整理成游客可以浏览、探索的景区预览。名称暂定，当前为黑客松原型。

景区人员在维护端管理地图、景点和多视角素材；游客从地图选择景点，查看实景照片，并进入已接入的三维空间。当前试点为**西湖花港观鱼·御碑亭**。

**[在线体验](https://jingjian-westlake-2026.raremint.chatgpt.site/#map)** · **[御碑亭三维试点](https://jingjian-westlake-2026.raremint.chatgpt.site/#pilot)** · **[景区维护端](https://jingjian-westlake-2026.raremint.chatgpt.site/#studio)** · **[文档目录](docs/README.md)**

## 当前能体验什么

截至 2026-10-12，公开站点已发布第 4 版。

| 能力 | 当前实现 |
| --- | --- |
| 游客地图 | 一张 AI 插画地图，六处真实景点，点位可点击进入详情；地图不是地理导航 |
| 实景照片 | 御碑亭、断桥、平湖秋月、曲院风荷、三潭印月、雷峰塔，附来源与许可 |
| 六视角审核 | 正面、左右两侧、背面、俯视、内部或近景；上传、查看、接受或移除 |
| AI 补图 | 内置 imagegen 预生成的五张御碑亭补图；网页按钮模拟返回固定样例，未接实时补图 API |
| 真实世界模型 | 御碑亭已有 Marble 1.1 生成的 SPZ，可环顾、移动、升降和重置 |
| 新建世界模型流程 | 新维护端运行模拟任务，不生成新资产、不消耗 API 额度 |
| 发布预览 | 草稿与游客快照独立；发布只影响当前浏览器，不是上传到云端 |
| 双语导览 | 保留在旧版概念场景与高级工作台；尚未整合进新的御碑亭页面 |

御碑亭模型的实际输入是**一张正面实拍**。五张 AI 补图没有送入这次世界生成。模型的未见区域是推测，不能保证完整、精确或实际可通行；其余五个景点当前提供照片预览。

## 本地启动

准备 Node.js 与 pnpm；本机验证使用 Node.js 24.19.0。依赖版本由 [pnpm-lock.yaml](pnpm-lock.yaml) 固定。

```sh
git clone https://github.com/Arlencl/hackathon-2026.git
cd hackathon-2026
pnpm install --frozen-lockfile
pnpm run build
pnpm start
```

打开 [本地景区地图](http://127.0.0.1:4173/#map) 或 [本地三维试点](http://127.0.0.1:4173/#pilot)。观看仓库自带的场景不需要模型密钥，也不会再次生成或扣费。

`dist/` 不提交到 Git。修改源码后重新执行 `pnpm run build`，再刷新浏览器；当前开发服务没有自动构建。已构建后也可在 macOS 双击 [启动景见.command](启动景见.command)。完整配置和故障处理见 [开发与部署](docs/开发与部署.md)。

## 页面入口

| 路径 | 用途 |
| --- | --- |
| `/#home` | 首页 |
| `/#map` | 游客地图与景点列表 |
| `/#spot?id=huagang` | 御碑亭六视角详情与三维入口 |
| `/#pilot` | 御碑亭实拍驱动的真实三维试点 |
| `/#studio` | 新维护端：地图 → 素材 → 世界模型演示 → 发布本机预览 |
| `/#world` | 旧湖景的真实生成资产，输入为 AI 概念图 |
| `/#tour` | 旧版五点位程序场景、资料问答与发布演示 |
| `/#legacy-studio` | 旧版双语资料维护与本机真实 API 适配 |
| `/#pitch` | 早期路演页面；最新讲稿以文档为准 |

`/#world` 和 `/#pilot` 是两个不同资产。演示真实景点试点请进入 `/#pilot`。

## 验证与当前边界

```sh
pnpm test
pnpm run build
```

截至 2026-10-12，最近一次完整测试为 24 项通过；本地和公开站点已检查六视角显示、三维加载、移动与重置。此记录不代表每台设备的性能保证。

上传地图、照片和新维护端发布内容保存在浏览器 IndexedDB。其他人访问公开链接会看到内置演示，不会收到你的本机草稿。新工作流支持导出含上传图片的备份，目前没有对应的备份恢复界面；旧版导览有另一套导入与版本管理。

尚未完成景区账号、云端素材发布、多人协作、实时补图 API、完整多视角世界生成链路和现场精度验收。真实服务的可选配置见 [.env.example](.env.example)；密钥、`data/` 和本地验收产物均不应提交。
