- [UNESCO：West Lake Cultural Landscape of Hangzhou](https://whc.unesco.org/en/list/1334/)

## 三维概念场景

`src/viewer.js` 中的湖水、亭、桥、岛屿、树木和远山均由程序生成。五个点位名称是演示策展标签，坐标和停留时间均为产品演示设定，不代表西湖真实景点空间测绘或运营信息。

## Marble 生成湖景

2026-10-10 使用本项目 `westlake-concept.png` 作为单图输入，经 Marble 1.1 API 生成。SPZ 为真实生成资产，不是由程序搭建的替代画面。生成任务、输入与资产哈希、积分和坐标元数据记录在 `public/assets/world/generation.json`。参考图与生成资产均不构成西湖实景测绘证据。
