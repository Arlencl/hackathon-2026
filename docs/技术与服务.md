# 技术选型与真实服务接入

调研日期：2026-10-10。官方 API 与价格仍可能变化，实际提交前以平台为准。

## 世界模型：World Labs Marble

[快速开始](https://docs.worldlabs.ai/api) 提供文字、图片、多图、视频生成方式。当前本地适配支持文字与公开图片 URL。

- POST `https://api.worldlabs.ai/marble/v1/worlds:generate`
- Header：`WLT-Api-Key`
- 默认模型 `marble-1.1`，可通过环境变量调整。
- GET `/marble/v1/operations/{operation_id}` 查询异步任务。
- 完成后按 world ID 调用 GET `/marble/v1/worlds/{id}` 获取完整资产。优先选择 `500k`，必要时用 `100k`。

本次使用用户已登录的 [World Labs Platform](https://platform.worldlabs.ai/) 账号和明确授权创建的 API 密钥。账户原有 7,000 credits；实际完成一次单图生成，消耗 1,580，剩余 5,420。没有充值或绑定支付。

[官方计费](https://docs.worldlabs.ai/api/pricing)：查询当日 1 美元对应 1,250 credits，最低购买 5 美元；标准 `marble-1.1` 文字或普通单图生成合计 1,580 credits（约 1.264 美元），实际账单以平台为准。API 与 Marble 网页版使用不同额度。不要为了这次演示启用不必要的自动充值。

当前代码已实现提交、状态查询和资产加入草稿。生成耗时不固定，演示优先展示已生成且明确注明来源的场景，再展示提交与任务状态。不会播放假进度。

公开参考图只能使用已确认允许上传、处理的图片。参考图可能影响结果，但不能保证几何、材质或历史事实准确；发布仍需核验。

## 播放器：Three.js + Spark

[Three.js](https://threejs.org/docs/) 管理摄像机、三维对象、控制和渲染；[Spark](https://sparkjs.dev/docs/overview/) 处理 Gaussian Splat 资产。

本版生成资产与程序场景均可由本机静态文件加载；Spark 按需加载。已下载真实 Marble 输出，使用 500k SPZ。资产尺寸、设备 GPU 和浏览器决定性能，未宣称全设备帧率达标。

生成样例使用独立策展视角与资料。播放器按 [官方坐标说明](https://docs.worldlabs.ai/api/rendering-spz) 应用本场景的 scale、ground offset 和 X 轴 180° 旋转。元数据只校正渲染，不能据此推断实地距离或无障碍条件。尚未实现碰撞和通用空间校准编辑器。

## 数字导游

默认：`answerGuide()` 根据问题意图和当前点位返回已发布资料。它是可解释的检索示范，没有声称调用 LLM。

可选：本地 `/api/guide` 使用兼容 Chat Completions 的服务端适配。用户配置 base URL、key、model；关键不确定类型优先返回未知。模型仅收到所选点位、用户问题和许可来源 ID，返回的文本按纯文本渲染，引用 ID 必须属于发布资料。无效响应或超时回退到检索。

格式与引用 ID 校验不能证明模型表达的每一个事实都正确。真实模型接通后仍需用固定问题集人工核验，不能把提示词限制宣称为形式化事实保证。

## 分层设计

```text
伙伴端导入资料 → 草稿（结构化点位 + 来源 + 中英文）
                           ↓ 人工核验
                      不可变发布快照
                      ↙          ↘
            三维场景/点位          导游检索/可选模型表达
                      ↘          ↙
                       游客端体验
```

localStorage 保存同一浏览器工作空间；IndexedDB 保存参考图片；本机 Node 保存独立分享快照与世界生成任务记录。私有 Sites 托管静态前端，不包含模型代理。未来公网版需要带鉴权的后端、持久数据库、限额、审计与资产存储，不能把本机服务直接暴露公网当成完整多人产品。

## 验证策略

Node 单元测试验证：草稿发布隔离、双语完整性、来源与使用权门槛、未知处理、时间预算、导入约束。

Playwright 验证：实际浏览器场景与点位联动、编辑审核发布/回滚、分享快照、文本与图片导入、splat 解码、路演打印与两种窄屏尺寸。

首版工作流验证见 `artifacts/qa-report.json`；本次世界模型链路记录见 `artifacts/world-trial/`。语音质量、伙伴效率和公网多用户访问尚未验证。

## 漫游控制修正

旧版的四米范围限制是播放器约束，不是 World Labs 的额度或范围限制。修订后解除硬限制，支持持续移动、加速和升降，三个预设位置在空间上相隔约 5.4–9.6 个模型米。姿态与位移分开处理，切换语言时沿用所选观景位置。方位图只表示虚拟观景点，不是实地路线。

单张概念图生成的资产仍有遮挡后表面缺失、近景形变等问题；自由相机不会生成新几何。当前未将 collider.glb 接入碰撞，也没有宣称湖面可以步行。
